# Vocabulary notebook

For grammar lessons based on a book and a topic keyword/unit, read and follow `03-grammar/skill.md` and update `03-grammar/grammar.html` in place. Keep this HTML empty until the first lesson is requested. Common supporting sentence structures belong in `04-common-structures/common-structures.html`, following `04-common-structures/skill.md`; link directly to their anchors from grammar instead of embedding their explanations there. This book-based workflow takes precedence over the standalone sentence-structure workflow for examples belonging to those lessons.

For requests to add, note, or edit English vocabulary in this workspace, read and follow `01-vocabulary/skill.md`. Search the common notebook (`01-vocabulary/common-vocabulary.html`) first, then the less-common notebook. Add new words absent from both to `01-vocabulary/less-common-words.json` and generate `01-vocabulary/less-common-vocabulary.html` with the same template, navigation, and US/UK audio. Requested new noun/adjective/adverb/verb family forms belong in the less-common notebook when their exact form/part of speech/sense is not already covered; avoid duplicate entries. Preserve existing common entries and IDs. The HTML notebook is the maintained learning artifact; do not create a Markdown vocabulary notebook. Respect requests for chat-only explanations without saving.

For sentence-structure/grammar notes based on sentences supplied by the user, read `02-sentence-structures/skill.md` and update `02-sentence-structures/sentence-structures.html`. Use the vocabulary notebook's template: a basic structure and a few useful related structures, each followed immediately by its example, US/UK IPA/audio and translation. Prefer the user's own sentence; label any adapted examples. The former connected-speech notebook has been replaced by this section. Do not create a Markdown grammar notebook.

For phrase requests, maintain `01-vocabulary/phrases.json` and generate `01-vocabulary/english-phrases.html` using the vocabulary template. Split each phrase into words, check all vocabulary sources, add only missing words to the vocabulary notebook, and link each component to its vocabulary anchor. Follow the phrase workflow in `01-vocabulary/skill.md`.
